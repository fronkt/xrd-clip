# Refute pass 1: xrd-clip literature claims (lit_A_ml_retrieval.md + lit_D_levers.md)

Checked 2026-10-10 against primary sources: arXiv export API metadata (all 14 arXiv IDs resolved), arXiv HTML/PDF full text, Europe PMC, Crossref, OpenAlex, bioRxiv API, IUCr abstract page. No browser, no proxy, no keyed publisher API.

Verdict key: CONFIRMED = matches the source. CORRECTED = the paper exists and the gist holds, but a number, a scope or a framing is wrong or missing. REFUTED = the source contradicts the claim. UNVERIFIABLE = could not be checked against the primary source.

| 4 XRDiff | **CORRECTED** | Segal, Li, Miller, Gómez-Bombarelli. Numbers are right: on 148 RRUFF structures, un-augmented full spectrum gives "match rates below 1% at a single attempt". (ii) Full spectrum **with fitted background-noise augmentation** gives "substantial gains". Under OQMD-Poly it is "largely comparable" to peak-based ("approximately one to two additional correctly matched structures"). So "full-spectrum encoding collapses on real data" holds only for *un-augmented* full spectra. The paper's actual argument is that peaks match heavy augmentation with less overhead. Note: the augmented-full bar heights appear only in Figure 6, so I did not read exact values. | https://arxiv.org/html/2606.14003v1 (Section 4, "Experimental Data") |

ICEBERG was scored on MassSpecGym's **spectrum-simulation** challenge. That challenge is restricted to [M+H]+ adducts and uses mass-based candidates (at most 256). The MassSpecGym paper's own simulation baseline FraGNNet already gets **46.64% hit@1** in that setting. **MIST** 14.64% hit@1 (mass-based candidates) and 9.57% (formula-based bonus) come from the **molecule-retrieval** challenge, which uses all adducts ([M+H]+ and [M+Na]+). **JESTR** 11.85% is **formula-based** candidates; its mass-based figure is 15.62%.
